第三阶段 · 后处理修正链
🛡️ 三道防线把守输出质量
LLM 输出不可全信，三道后处理防线确保结果安全可靠
4
✂️ OCR 文本智能截断
超 2500 字时，不简单截头去尾，而是保留高风险关键词附近的内容。
5
🛡️ 低风险安全措辞过滤
禁止 LLM 使用绝对安全表述：
「内容安全」→ 「未发现明显风险」
「可以放心」→ 「建议进一步核实」
「无风险」→ 「请勿完全依赖系统判断」
6
🔗 案例语义匹配后处理
LLM match=true → 绑定案例详情 + 触发风险升级 (caution→high)
LLM 未返回 caseMatch → 本地关键词兜底引擎接管
7
💾 缓存结果 + 数据标准化
结果写入 localStorage（key=图片Hash），normalizeResult() 做字段兼容与类型安全转换。

⚡ 即使 API 崩溃，用户也能拿到结果
多层兜底策略确保极端情况下系统仍可降级运行
异常场景兜底策略
网络断开显示网络错误提示 + 引导重试按钮
API 超时 (>90s)最多重试 3 次（2s/4s/6s 递增延迟）→ 仍失败走完全兜底
JSON 解析全部失败fallbackFromRawText() — 从原始响应中用正则提取关键词，走本地关键词引擎判断
所有重试均失败makeEmptyFallbackResult() — 返回 low + 「系统繁忙」提示 + 防骗建议
图片过大 (>10MB)自动压缩后再发送；超时时在兜底文案中提示
