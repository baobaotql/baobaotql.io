# 灵溪识险 · 项目记忆

## 项目概述
- 项目名：灵溪识险（Silver Finance Safety Assistant）
- 类型：UniApp + Vue 3 微信小程序
- 核心功能：拍照/截屏识别金融诈骗风险，面向老年用户
- 架构：Serverless 轻架构（前端直调智谱 GLM-4.6V，无传统后端）

## 技术栈
- 前端：UniApp + Vue 3（小程序模式）
- AI：智谱 GLM-4.6V 多模态视觉模型（OCR + 风险分析一体化）
- 案例库：本地关键词匹配（零 token 消耗）
- 存储：localStorage（图片缓存 + 分析历史）

## 关键设计决策
- 无服务器架构：降低运维成本，天然隐私友好（用户数据不经过我方服务器）
- 案例库打包在代码中（20 个案例，10+ 类别），匹配在本地完成
- 识别优先级：大模型初判 → 案例库后置调权（强匹配可覆盖模型判断）
- API Key 安全性需后续通过 uniCloud 云函数代理解决
